# Civora

Çevrimiçi strateji ve yaşam oyunu. Bu depo yalnız oyunun yayımlanmış ekranlarını taşır; her gönderimde GitHub Pages'e yayımlanır.

- Oyun: bu deponun GitHub Pages adresi (Settings → Pages).
- Gizlilik ve oyun kuralları: sitedeki `gizlilik.html`.
- Sorun ve öneriler: oyun içindeki Geri bildirim formu (Hayatım → Ayarlar).

Bu klasördeki dosyalar elle düzenlenmez; derleme aracıyla üretilir.
